## Getting Started in 60 Seconds

1. Flash the OS image to a microSD card (use [balenaEtcher](https://etcher.balena.io/) or `dd`).
2. Insert the SD card into rhinoPi X1.
3. Connect HDMI, USB keyboard, and 5V/3A USB-C power.
4. Power on — the system boots to a desktop in ~15 seconds.

```bash
# Optional: headless setup via USB-C serial (115200 8N1)
sudo apt update && sudo apt full-upgrade -y
sudo apt install -y git python3 python3-pip
```
