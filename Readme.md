# rhinoPix1 Blog 🦏

A cyberpunk-themed, bilingual (English / 简体中文) personal blog built with [Docusaurus 3](https://docusaurus.io/), deployed to GitHub Pages.

🌐 **Live site**: https://yoyojacky.github.io/rhinopix1_blog/
💻 **Repo**: git@github.com:yoyojacky/rhinopix1_blog.git

---

## ⚡ Quick Start (5 minutes)

```bash
# 1. Clone
git clone git@github.com:yoyojacky/rhinopix1_blog.git
cd rhinopix1_blog

# 2. Install deps (Pi: ~2 min, laptop: ~30s)
yarn install

# 3. Start dev server (English only — see i18n note below)
yarn start
# → http://localhost:50011/rhinopix1_blog/

# 4. Build for production (full i18n)
yarn build && yarn serve
# → http://localhost:50012/rhinopix1_blog/
```

## 📜 Available Scripts

| Command | Port | Purpose |
|---------|------|---------|
| `yarn start` | 50011 | Dev server with hot reload (English) |
| `yarn build` | — | Production build into `build/` |
| `yarn serve` | 50012 | Preview the production build (full i18n) |
| `yarn clear` | — | Clear Docusaurus + webpack cache |
| `yarn docusaurus write-translations --locale zh-Hans` | — | Generate i18n translation stubs |

> **⚠️ Dev server caveat**: Docusaurus 3 dev server does NOT fully render i18n pages (only English content). To preview bilingual content, **always use `yarn build && yarn serve`**.

## ✍️ Adding Content

### New blog post

1. Create `blog/YYYY-MM-DD-my-slug.md` with frontmatter:
   ```yaml
   ---
   slug: my-slug
   title: My Title
   authors: [rhinoPix1]
   tags: [tag1, tag2]
   ---
   ```
2. Add `<!-- truncate -->` after the first 1–2 paragraphs (controls list-page preview).
3. (Optional) Translate to Chinese: `i18n/zh-Hans/docusaurus-plugin-content-blog/YYYY-MM-DD-my-slug.md` (same frontmatter, same `slug`).

### New doc page

1. Create `docs/<section>/my-page.md` with frontmatter:
   ```yaml
   ---
   title: My Page
   sidebar_label: Short Label
   sidebar_position: 1
   tags: [tag1, tag2]
   ---
   ```
2. Sidebar is `autogenerated` — no manual registration needed.
3. (Optional) Translate: `i18n/zh-Hans/docusaurus-plugin-content-docs/current/<section>/my-page.md`.

## 🌐 Internationalization (i18n)

### Workflow

1. **First time / after editing English content** — refresh translation stubs:
   ```bash
   yarn docusaurus write-translations --locale zh-Hans
   ```
   This regenerates `i18n/zh-Hans/code.json` and per-plugin option files.

2. **Edit translations** — fill in the Chinese text in:
   - `i18n/zh-Hans/code.json` (UI strings — already has 92 entries)
   - `i18n/zh-Hans/docusaurus-theme-classic/navbar.json` (navbar labels)
   - `i18n/zh-Hans/docusaurus-plugin-content-blog/*.md` (blog posts)
   - `i18n/zh-Hans/docusaurus-plugin-content-docs/current/**/*.md` (docs)

3. **Verify** — always preview with:
   ```bash
   yarn build && yarn serve
   # open http://localhost:50012/rhinopix1_blog/zh-Hans/
   ```

### ⚠️ Critical i18n Pitfalls (learned the hard way)

| Pitfall | Symptom | Fix |
|---------|---------|-----|
| Missing `translate: true` in `localeConfigs.zh-Hans` | Chinese page never renders | Add it — see `docusaurus.config.js` |
| Link in Chinese doc uses `/zh-Hans/blog/...` | Build error: `/zh-Hans/zh-Hans/...` | Inside `i18n/zh-Hans/`, **drop** the `/zh-Hans/` prefix from links |
| Image referenced but missing in `static/img/` | MDX compilation error | Either add the image or remove the reference |
| Blog link to `/blog/tags/<unused-tag>` | "broken link" build error | Only link to tags that exist OR link to `/blog/tags` (all-tags page) |
| Missing `yarn docusaurus write-translations` after config change | `codeTranslations.json` is `{}` | Run it after any i18n config change |

## 🚀 Deployment

Deployment is automatic via **GitHub Actions** on every push to `main`.

### First-time setup (one-time, in browser)

1. Go to https://github.com/yoyojacky/rhinopix1_blog/settings/pages
2. Under **Source**, choose **GitHub Actions**
3. Save

### Deploy workflow

```bash
git add .
git commit -m "feat: ..."
git push origin main
# → GitHub Actions runs yarn build + deploys to Pages (~2 min)
```

Site appears at: https://yoyojacky.github.io/rhinopix1_blog/

### Workflow file

See `.github/workflows/deploy.yml`. Key settings:
- Node.js 20
- `NODE_OPTIONS="--max-old-space-size=6144"` (Pi-safe + GitHub runner safe)

## 🎨 Theming (Cyberpunk Neon)

All visual customization lives in **`src/css/custom.css`**. CSS variables at the top:

```css
:root {
  --rhp-bg: #0a0e1a;          /* Deep space black */
  --rhp-neon-cyan: #00f0ff;   /* Neon cyan */
  --rhp-neon-pink: #ff2e88;   /* Neon pink */
  --rhp-neon-purple: #b16cff; /* Neon purple */
  --rhp-font-mono: 'JetBrains Mono', 'Fira Code', ...;
  /* ... */
}
```

**To change colors**: only edit the variable values, not the rules below them.

**To add new themed styles**: append to `custom.css` — the existing 12 sections cover: base, headings, links, navbar, sidebar, code, footer, buttons, admonitions, scrollbar, selection.

## 🛠️ Troubleshooting

### Build errors

| Symptom | Cause | Fix |
|---------|-------|-----|
| `Module not found: '@generated/i18n'` | Stale `.docusaurus/` cache | `yarn clear && rm -rf node_modules/.cache && yarn start` |
| `Can't resolve 'lunr.zh-Hans.js'` | Plugin doesn't support `zh-Hans` locale code | Use `language: ['en', 'zh']` in search plugin config |
| `blog.blogSidebarTitle is not allowed` | Removed in Docusaurus 3.x | Delete the `themeConfig.blog` block |
| `authors map file could not be loaded` | Frontmatter references unregistered author | Create `blog/authors.yml` + set `authorsMapPath` in config |
| `your current branch 'main' does not have any commits yet` (during build) | Docusaurus reads git log for `lastUpdated` | Set `showLastUpdateTime: false` (already done) |
| `MDX compilation failed` / image not found | Referenced image missing | Add image to `static/img/` or remove the reference |
| `Docusaurus found broken links!` | Internal link to nonexistent route | Use `yarn build` to see the exact broken path; fix or remove |
| `non-fast-forward` on `git push` | Remote has commits not in local | `git pull --rebase origin main && git push` |
| GitHub Actions OOM | GitHub runner has 7 GB, Docusaurus peak ~5 GB | `NODE_OPTIONS="--max-old-space-size=6144"` (already set) |

### Network / firewall

If Windows / LAN cannot reach the Pi at `:50011` or `:50012`:
```bash
# Pi side — open the port
sudo ufw allow 50011/tcp
sudo ufw allow 50012/tcp

# From Windows, ping Pi first:
# ping 192.168.3.250
```

### Cache reset (the nuclear option)

```bash
yarn clear
rm -rf .docusaurus node_modules/.cache build
yarn start
```

## 📝 Commit Convention

Follow `AGENTS.md` section 9:

- `blog: <date>-<slug>` — new blog post
- `docs: <brief>` — docs change
- `style: <brief>` — CSS / theme
- `chore: <brief>` — config / deps
- `feat: <brief>` — new feature
- `fix: <brief>` — bug fix
- `ci: <brief>` — CI / workflow

Atomic commits. Don't pile unrelated changes together.
